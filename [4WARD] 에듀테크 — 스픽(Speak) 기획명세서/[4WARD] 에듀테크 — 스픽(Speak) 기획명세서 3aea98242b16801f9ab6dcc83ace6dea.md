# [4WARD] 에듀테크 — 스픽(Speak) 기획명세서

# 복습 기능 개선 — 레벨 및 코스 선택

## 1. 목표

- **서비스 목표** : 스픽 사용자가 이전에 학습한 표현을, 검색어 없이도 **‘레벨’**과 **‘코스’**라는 이미 알고 있는 축으로 다시 찾아 복습할 수 있게 한다.
- 핵심 가치 : 시스템이 대신 추천해주는 복습(Smart Review)과는 별개로, 사용자가 스스로 원하는 표현에 도달하는 탐색 경로를 제공한다.

## 2. 배경

### 2-1. 시장 조사 요약

- 에듀테크 시장은 콘텐츠 제공 중심에서 **AI 기반 개인화 학습 경험 중심**으로 이동 중
- 시장 공통 문제 : 낮은 학습 지속률, 개인화 부족, AI 신뢰성 이슈 반복
- 언어학습 서비스에서는 AI 활용 여부보다 **학습 경험을 하나의 흐름으로 연결**하는 것이 경쟁력으로 부상

### 2-2. 경쟁사 비교 — 복습 관련 기능 보유 현황

| 서비스 | 저장 | 검색 | 자동 추천 | 취약 표현 | 빠른 복습(진입 단계) |
| --- | --- | --- | --- | --- | --- |
| Speak | O | △ | △ | O | △ |
| Busuu | O | O | O | O | O |

- 스픽은 **‘표현 저장’**과 **‘취약 표현(스마트 리뷰)’**은 갖추고 있으나, 저장한 표현을 스스로 검색·탐색하는 기능은 상대적으로 약함.

### 2-3. 왜 ‘검색’이 아니라 ‘레벨·코스 탐색’인가

<aside>

> 경쟁사 다수가 검색 기능보다 자동 복습 추천에 집중하는 이유(가설) :
> 
1. 검색은 리텐션·매출과 직접 연결되지 않으며, 자동 추천이 학습 지속에 더 효과적이라고 판단
2. 커리큘럼·영상클립 기반 콘텐츠는 검색 가능하도록 구조화/태깅하는 비용이 큼
3. 초·중급 학습자는 정확한 스펠링/용어를 몰라 검색어 입력 자체가 어렵고, 음성 인식 중심 서비스에서는 텍스트 검색 UX가 정책과도 상충
4. 기존 AI 튜터에서 검색 및 질의응답 기능을 제공하고 있어, 본 기능은 검색을 대체하기보다 학습 이력을 탐색하며 복습하는 경험에 집중함

→ 따라서 **자유 검색창 대신**, 이미 존재하는 **레벨/코스 분류 축을 탐색 경로로 재사용**하는 방향이 스픽 특성에 더 부합

</aside>

🔹복습 관련 VOC 세부 분류(95건 중)

| 세부 카테고리 | 건수 | 중요도 | 대표 VOC |
| --- | --- | --- | --- |
| 복습 콘텐츠 접근 | 26건 | 매우 높음 | 예전에 배운 표현을 다시 보고 싶어요 / 지난 레슨을 찾기가 어렵습니다 |
| 자동 복습 | 21건 | 매우 높음 | 자동으로 복습시켜 주세요 / 복습 알림이 있으면 좋겠습니다 |
| 표현 저장 | 18건 | 높음 | 단어장을 만들어 주세요 / 표현 저장 기능이 필요합니다 |
| 개인 맞춤 복습 | 13건 | 높음 | 잘 못하는 것만 복습하고 싶어요 |
| 복습 진행 관리 | 10건 | 보통 | 복습 진도가 안 보입니다 |
| 복습 동기부여 | 7건 | 보통 | 며칠 지나면 안 하게 됩니다 |
- ‘복습 콘텐츠 접근(26건)’이 최다이며, 나머지도 결국 **`원하는 콘텐츠를 먼저 찾을 수 있어야`** 성립하는 하위 니즈라는 공통점
- 접근성 문제를 우선 해결하면 다른 복습 기능의 활용도도 함께 오를 가능성

### 2-5. 기존 서비스 한계(AS-IS)

- 현재 ‘연습’ 탭의 복습 관련 진입점은 **‘스마트 복습(자동 추천)’**과 **‘저장된 문장 보기(직접 저장한 것)’** 2가지로 한정
- **`레벨·코스 단위로 학습 이력 전체를 탐색`**할 수 있는 진입점이 없음
→ 저장하지 않은 표현은 다시 찾기 어려움

## 3. 핵심 타겟

- 정의 : 스픽에서 특정 레벨 또는 코스를 학습한 이력이 있고, 그 표현을 **스스로 다시 찾아 복습**하려는 의도가 있는 사용자
- 근거 : “예전에 배운 표현을 다시 보고 싶어요”, “지난 레슨을 찾기가 어렵습니다”는 **`탐색을 시도했다가 실패한 사용자 발화`**
- 비핵심 타겟 : AI가 골라주는 대로 복습하는 수동적 사용자는 1차 타겟 아님(기존 스마트 복습이 담당)

## 4. 문제정의 및 솔루션 가설

### 4-1. 우리가 해결하려는 문제

> 현재 스픽은 복습 기능(스마트 리뷰, 저장 표현 보기)을 제공하지만,
사용자가 이전에 학습한 표현을 **레벨·코스 단위로 직접 찾아 복습 대상으로 불러올 수 없다.**
→ 복습 기능의 활용 범위가 제한됨
> 

### 4-2. 사용자 페인포인트[VOC]

- “예전에 배운 표현을 다시 보고 싶어요.”
- “지난 레슨을 찾기가 어렵습니다.”
- “배운 문장이 어디 있는지 모르겠어요.”

### 4-3. 핵심 문제 정의

> 사용자가 이전에 학습한 표현을 직접 찾아 복습 대상으로 불러올 수 없어
원하는 콘텐츠를 반복 학습하기 어렵다.
→ 서비스는 복습 기능의 활용 범위와 효과적인 복습 경험을 확장하지 못하고 있다.
> 

### 4-4. 중요성 — 왜 지금인가

- 복습 VOC : 54건 → 95건(▲76%), 그중 ‘복습 콘텐츠 접근’ 26건(최다)
- 건수가 줄지 않고 늘었다는 것은 개선되지 않은 채 누적된 신호
- 경쟁사 대비 ‘검색·탐색’이 약해 경쟁 열위 발생 가능

### 4-5. 해결 방식(채택안) & 제외한 대안

- **채택안** : ‘연습’ 탭에 **`‘레벨 및 코스 선택’`** 진입점 신설
→ 레벨(왕초보~마스터) 또는 코스(토픽별/스페셜/이전 버전) 단위로 학습 문장 탐색
- **제외** : 자유 텍스트 검색(태깅 비용, 초급자의 검색어 입력 부담, 음성 UX 부정합)

### 4-6. 솔루션 가설 & 검증 지표(안)

> **`핵심 가설`**
복습 콘텐츠를 레벨·주제별로 구조화하여 사용자가 원하는 표현을 쉽게 탐색하고 검색할 수 있도록 개선한다면, 반복 학습이 활성화되어 콘텐츠 재방문율과 복습 완료율이 증가할 것이다.
> 

| 가설 | 검증 지표(안) |
| --- | --- |
| 레벨·코스 기준 탐색 제공 → 복습 포기 감소 | 레벨/코스 선택 진입율, 문장 리스트 도달률 |
| 복습 콘텐츠 구조화 → 재방문율·완료율 증가 | 재방문율, 북마크 저장 전환율 |
| 저장 기능과 연결된 탐색 경로 → 저장 기능 활용 증가 | 북마크 저장 건수, 저장된 문장 보기 재방문율 |
| 학습한 문장 보기 → 각 문장별 음성 듣기 사용성 증가 | 음성 듣기 클릭률 |

## 6. 기대효과

### 6-1. 성공지표(KPI) — 방향성 지표

※ 신규 기능으로 베이스라인이 없어, 출시 후 1~2주 데이터 확보 후 목표치 설정

| 구분 | KPI | 목표 | 선정 이유 |
| --- | --- | --- | --- |
| **Main KPI** | **복습 완료율**
(레벨/코스 선택 진입자 중, 문장 리스트에서 음성 듣기 또는 북마크로 실제 재학습 후 복습 완료까지 도달하는 비율) | Baseline 대비 지속 증가 | 4-3 문제정의('찾아서 실제로 다시 학습할 수 있는가')와 4-6 핵심 가설을 진입→도달→활용→완료 전 구간으로 종단 검증하는 유일한 지표 |
| Sub KPI | 레벨/코스 선택 진입율 | Baseline 대비 지속 증가 | 신규 진입점에 대한 인지·최초 사용 여부 확인 |
| Sub KPI | 문장 리스트 도달률 | Baseline 대비 지속 증가 | 레벨/코스 → 유닛/챕터 선택 단계에서 이탈이 발생하는 구간 확인 |
| Sub KPI | 음성 듣기 클릭률 | Baseline 대비 지속 증가 | 찾은 표현을 그 자리에서 실제로 학습(듣기)하는지 확인 |
| Sub KPI | 북마크 저장 전환율 | Baseline 대비 지속 증가 | 찾은 표현을 다음에도 다시 보기 위해 저장하는 행동으로 이어지는지 확인 |
| Sub KPI | 복습 기능 재방문율(D7/D30) | Baseline 대비 지속 증가 | 탐색 경로 제공이 일회성 사용에 그치지 않고 반복 습관으로 이어지는지 확인 |

> 신규 기능 특성상 사전 데이터가 없어 초기 운영 데이터를 Baseline으로 설정하고,
이를 기준으로 지속적인 개선 여부를 측정한다.

### 6-2. Guardrail 지표

| 구분 | Guardrail 지표 | 기준 | 확인하려는 것 |
| --- | --- | --- | --- |
| **Main Guardrail** | **기존 '스마트 복습' 이용률** | **출시 전 대비 유의미한 감소 없음** | **신규 기능이 기존 자동 추천 복습을 잠식하는지 확인 — 잠식되면 복습 기능 전체 구조를 재검토해야 함** |
| Sub Guardrail | 연습 탭 초기 화면 이탈률 | 출시 전 대비 증가 없음 | 메뉴 추가로 인한 정보 과부하 여부 |
| Sub Guardrail | 레벨/코스 선택 → 문장 리스트 단계별 이탈률 | 특정 단계 이탈 50% 이상 시 경고 | 레벨→유닛→문장 3단계 진입이 과도한 이탈을 유발하는지, 스픽의 기존 강점(짧은 진입 경로)을 해치는지 확인 |
| Sub Guardrail | 음성 재생·북마크 오류 발생률(4-1, 4-2 연동) | 오류 토스트 노출 빈도 임계치 이내 | 예외 케이스 처리 미흡이 실제 사용 경험을 저해하는지 확인 |

### 6-3. 리스크

- 콘텐츠 공백에 따른 유료가치 훼손 : 스페셜 코스·이전 버전 커리큘럼은 비정기 업데이트 대상 → 이미 결제한 프리미엄 사용자가 빈 문장 리스트를 만나면 '돈 내고 쓰는데 콘텐츠가 없다'는 불만으로 직결
- 정체성 상충 : 스픽의 강점은 짧고 자동적인(push) 진입 경로 → 이번 기능은 3~4단계 탐색(pull) 구조로 반대 방향
- 레벨×코스 이중 분류 혼란 : 동일 표현이 레벨·코스 양쪽에 존재 가능 → 어느 축에서 찾아야 할지 판단 어려움
