# [4WARD] 에듀테크 — 스픽(Speak) 기능명세서

## 1. 핵심 기능 정의

| 항목 | 내용 |
| --- | --- |
| **기능명** | 레벨 및 코스별 학습 문장 복습 |
| **기능 한 줄 설명** | 사용자가 학습한 문장을 레벨·코스·유닛(또는 챕터)별로 모아 확인하고,
원하는 문장을 **음성 재생** 및 **북마크**로 다시 복습할 수 있게 합니다. |
| **핵심 선정 이유** | 사용자는 이전에 학습한 표현을 다시 확인하려고 해도 해당 표현이 어느 레벨·코스·유닛에 포함되어 있는지 찾기 어렵습니다. 
학습한 문장을 레벨/코스 기준으로 모아 제공하고, 원하는 학습 범위를 선택해 문장에 빠르게 재접근할 수 있도록 하여 **콘텐츠 접근성** 및 **재방문·복습 행동**을 개선합니다. |

## 2. User Flow

![유저플로우-수정.jpg](%5B4WARD%5D%20%EC%97%90%EB%93%80%ED%85%8C%ED%81%AC%20%E2%80%94%20%EC%8A%A4%ED%94%BD(Speak)%20%EA%B8%B0%EB%8A%A5%EB%AA%85%EC%84%B8%EC%84%9C/%EC%9C%A0%EC%A0%80%ED%94%8C%EB%A1%9C%EC%9A%B0-%EC%88%98%EC%A0%95.jpg)

### 2-1. 기본 흐름

```
연습 탭 진입
→ '레벨 및 코스 선택' 선택
→ 레벨 또는 코스 목록 확인
→ 레벨 또는 코스 카드 펼치기
→ 학습 완료된 유닛 또는 챕터 선택
→ 선택한 레벨·코스의 학습 문장 목록 확인
→ 문장 음성 재생 또는 북마크 저장
```

### 2-2. 분기 흐름

```
[연습 목록]
    ↓
[레벨 및 코스 선택]
    ├─ 레벨 선택
    │   ↓
    │ [레벨별 유닛 확인]
    │   ↓
    │ [레벨·유닛별 문장 목록]
    │
    └─ 코스 선택
        ↓
      [코스별 챕터 확인]
        ↓
      [코스·챕터별 문장 목록]
```

| 5 | 학습 문장 영역 | 선택 챕터와 연결된 수업의 문장 데이터를 학습 순서대로 표시 (영문 1줄, 한글 1줄) | 영역 초과 시 세로 스크롤 |
| 6 | 음성 재생 | 각 문장 우측 음성 아이콘 | 재선택 시 중지 |
| 7 | 북마크 | 각 문장 우측 북마크 아이콘 | 선택 시 저장/해제 |
| 8 | 문장 내용이 노출 화면보다 많을 경우 | 문장이 노출 화면보다 많을 경우, 코스 박스 범위 내 세로 스크롤 제공(스크롤 바 안 보이게) |  |

> 챕터·유닛 영역 / 음성 재생 / 북마크 이벤트는 화면 3-1과 동일한 로직을 따릅니다.
